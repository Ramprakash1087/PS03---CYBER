# PS03 – Ad Auditor

AI-powered system that verifies advertisement claims against landing-page content.

### Features
- AI claim extraction
- Landing-page analysis
- Claim verification
- Evidence & confidence scoring
- Audit dashboard & history

### Tech Stack
**React • FastAPI • Python • SQLite • AI**

**Flow:**  
`Ad → Claim Extraction → Landing Page → AI Verification → Audit Score`

Developed as a hackathon project.
